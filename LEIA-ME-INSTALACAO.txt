O SUPABASE JÁ FOI PREPARADO PELO CHATGPT.

COMO PUBLICAR NO GITHUB
1. Abra https://github.com/EuripedesBoni/boniverso-app
2. No repositório, localize boniverso-gestao-turmas-v300.js.
3. Substitua o conteúdo desse arquivo pelo JavaScript novo do pacote.
   Se usar Add file > Upload files, selecione o arquivo .js EXTRAÍDO,
   nunca o ZIP fechado. Confirme que o GitHub aceitou a substituição;
   em alguns casos ele solicita editar manualmente o arquivo existente.
4. Salve na branch main com Commit changes.
5. Não altere turmas.html: ele já usa o nome de arquivo acima.
6. Acesse https://euripedesboni.github.io/boniverso-app/turmas.html
   e atualize a página no Safari/iPad.

NOVIDADES
- Turmas ativas | Arquivadas | + Criar turma
- Criação de turma escolhendo 6º, 7º, 8º, 9º EF, 1ª, 2ª, 3ª EM
- Adicionar anos depois da criação
- Editar nome e descrição
- Matrículas: modificar ano e desativar/reativar
- Pausar e reativar cada ano; gerar código de matrícula por ano
- Excluir um ano vazio ou uma turma vazia, com confirmação
- Anos/turmas com matrículas, redações e demais registros NÃO são apagados;
  é possível pausá-los/arquivá-los preservando o histórico.
