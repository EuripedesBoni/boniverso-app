BONIVERSO — CORREÇÃO DO LAYOUT DAS CONVERSAS DO ESTUDANTE
VERSÃO v2.1 — substituição simples no GitHub

O QUE FOI CORRIGIDO
- Agora o CSS da caixa de entrada é realmente inserido na página.
- Os cartões são separados, brancos, com bordas e espaços próprios.
- Nome da turma, situação da última mensagem e ação ficam em linhas distintas.
- Filtros de busca e de respostas não lidas são responsivos no iPhone.
- A turma aberta recebe destaque visual.
- Nenhum texto privado de conversa é apresentado na lista.

INSTALAÇÃO
1. Acesse github.com/EuripedesBoni/boniverso-app
2. Abra a pasta raiz (principal) do repositório.
3. Substitua SOMENTE o arquivo boniverso-inbox-estudante-v1.js
   pelo arquivo de mesmo nome que está neste ZIP.
4. Clique em Commit changes.
5. Aguarde o GitHub Pages concluir a publicação.
6. Abra https://euripedesboni.github.io/boniverso-app/
   e entre com a conta de estudante. Acesse Mensagens.
7. Se ainda ver os cartões azuis antigos, atualize a página ou
   teste em uma guia privada com login.

IMPORTANTE
- NÃO altere index.html nem mensagens-turma-v3.html.
- NÃO renomeie o arquivo JavaScript: o HTML já o importa.
- NÃO execute migração SQL nem altere o Supabase.
- A segurança continua protegida por RLS no banco existente.
- Faça o teste visual no celular e no computador após a publicação.
