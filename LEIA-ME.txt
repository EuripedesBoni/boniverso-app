BoniVerso — Tela de MFA para administradores

1. Adicione o arquivo mfa-admin.html na RAIZ do repositório EuripedesBoni/boniverso-app, pelo GitHub (Add file > Upload files).
2. Aguarde a publicação do GitHub Pages e acesse https://euripedesboni.github.io/boniverso-app/mfa-admin.html
3. Entre com a conta euripedes_junoo@icloud.com. Não divulgue a senha.
4. Digitalize o QR code em um aplicativo autenticador e confirme o código de seis dígitos.
5. Guarde método alternativo de autenticação em local seguro. A tela não armazena chaves TOTP no banco da aplicação; somente o Supabase Auth gerencia os fatores.
6. No próximo acesso, confirme o código para obter sessão aal2. A regra do banco exige aal2 para contas de papel admin.

Observação: há recursos adicionais do BoniVerso que devem continuar recebendo testes de acesso. Esta página não substitui uma auditoria de RLS nem o ajuste da navegação do painel administrativo.
