BONIVERSO — INDICADORES DA PÁGINA INÍCIO CLICÁVEIS — v2

Por que esta atualização?
A correção anterior tornou clicáveis os quatro cartões do Painel do Professor.
Os quatro cartões exibidos na página Início (com o banner Aprenda. Evolua. Conquiste.) ainda não tinham navegação.

INSTALAÇÃO NO GITHUB
1. Envie boniverso-indicadores-inicio-v2.js para a raiz de EuripedesBoni/boniverso-app.
2. Edite index.html.
3. Logo abaixo da linha:
   <script defer src="./boniverso-editor-painel-v1.js?v=1"></script>
   acrescente:
   <script defer src="./boniverso-indicadores-inicio-v2.js?v=2"></script>
4. Clique em Commit changes e confira a publicação no GitHub Actions.
5. Abra o BoniVerso no iPad, atualize a página e teste a área Início.

ATUALIZAÇÃO DOS INDICADORES DA PÁGINA INÍCIO
• Cursos no catálogo -> lista de cursos.
• Tarefas concluídas -> Meu planejamento.
• Redações enviadas -> Oficina de redação.
• Aulas concluídas -> Meu aprendizado / Painel de Aprendizagem.

Não remova os arquivos de layout v1: eles continuam corrigindo o Editor de Cursos e o Painel do Professor.
Esta atualização não altera Supabase, tabelas, turmas ou matrículas.
