BONIVERSO — CORREÇÃO EMERGENCIAL v2.0.2

PROBLEMA CORRIGIDO:
A tela inicial podia ficar totalmente em branco porque o Web Push monitorava alterações
que o próprio módulo de notificações criava, causando um ciclo infinito no navegador.

COMO INSTALAR:
1. Abra o GitHub em https://github.com/EuripedesBoni/boniverso-app
2. Escolha Add file > Upload files.
3. Envie os 3 arquivos que estão dentro de ENVIAR-PARA-GITHUB:
   - boniverso-webpush-v201.js (SUBSTITUIR o existente)
   - sw.js (SUBSTITUIR o existente)
   - index.html (SUBSTITUIR o existente)
4. Clique em Commit changes e aguarde o GitHub Pages mostrar Success.
5. No computador, abra https://euripedesboni.github.io/boniverso-app/?v=202
   e faça Ctrl+Shift+R (atualização forçada).
6. No celular, feche e reabra o BoniVerso. Se ainda vir a tela anterior,
   abra uma nova aba do navegador e visite o endereço com ?v=202. Em iPhone,
   não é necessário apagar o app nem remover sua conta.

OBSERVAÇÕES:
- Esta é somente uma correção de interface; não apaga arquivos, notas nem matrículas.
- O Web Push continua disponível, sujeito à permissão do aparelho.
- Depois de abrir novamente, teste ativar notificações pelo ícone do sino.
- Se persistir a tela em branco, envie o erro do Console do navegador
  (F12 > Console) e uma captura da tela.
