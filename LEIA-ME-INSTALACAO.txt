BONIVERSO v1.7.1 — GÊNEROS PERSONALIZADOS EM PDF
============================================

INSTALE NO GITHUB (BRANCH main)

1. Descompacte o ZIP no aplicativo Arquivos do iPad.
2. No repositório EuripedesBoni/boniverso-app, use Add file > Upload files.
3. Envie APENAS o arquivo boniverso-genero-personalizado-v171.js para a RAIZ do repositório.
4. Clique em Commit changes.
5. Abra o arquivo gestao-redacoes.html no GitHub (branch main), clique em Edit (ícone lápis).
6. Encontre o trecho final:
   </script></body></html>
7. Substitua somente esse final por:
   </script><script type="module" src="./boniverso-genero-personalizado-v171.js"></script></body></html>
8. Clique em Commit changes. Aguarde o GitHub Pages mostrar Success.
