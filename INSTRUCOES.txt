BONIVERSO v1.0.1 — ATALHOS DAS TURMAS

1. Descompacte este ZIP.
2. Acesse github.com/EuripedesBoni/boniverso-app.
3. Use Add file > Upload files.
4. Envie estes quatro arquivos para a RAIZ do repositório, substituindo os existentes:
   - index.html
   - sw.js
   - turmas-home.js
   - turmas-home.css
5. Use Commit changes.
6. Abra https://euripedesboni.github.io/boniverso-app/?versao=101

Na conta do aluno, após matriculado, o cartão mostra sua escola e série.
Na conta do professor, mostra cartões para Jaó e Areião, com totais por série.
Os cartões são atalhos para turmas.html. As permissões de acesso permanecem no Supabase.
