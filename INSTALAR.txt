BoniVerso Live v1.1.9 — controles de gravação

1) No GitHub EuripedesBoni/boniverso-app, branch main, clique Add file > Upload files.
2) Envie o arquivo live-recording-controls.js para a RAIZ do repositório e confirme o commit.
3) Abra live-room.html, clique no lápis (Edit), vá até o FINAL.
4) Logo ANTES de </body>, mas DEPOIS do </script> do código atual, insira:

<script defer src="live-recording-controls.js"></script>

5) O final esperado é:

</script>
<script defer src="live-room-media-fix.js"></script>
<script defer src="live-recording-controls.js"></script>
</body>
</html>

6) Salve com Commit changes. Atualize a página da aula nos dois dispositivos.

SEGURANÇA E USO
- Não poste os valores das chaves R2 e LiveKit no GitHub ou na conversa.
- Gravação só inicia com professor autenticado, aula ao vivo e confirmação explícita do aviso.
- A página passa a mostrar o aviso de gravação a todos os participantes.
- Faça o teste apenas com contas de teste ou pessoas adequadamente informadas e autorizadas.
- Após encerrar, clique "Verificar processamento" até ficar pronto.
- Só depois clique "Publicar para alunos".
- Não é automático. O LiveKit Egress pode gerar cobrança após a franquia gratuita.
- Os alunos veem somente gravações prontas e publicadas dos cursos/turmas autorizados.
- A gravação é uma função experimental: ainda não foi testada ponta a ponta com upload para o R2.
